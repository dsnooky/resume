# Resumé Online Maker

A responsive static landing page for GitHub Pages.

## Files
- `index.html` — page structure and content
- `style.css` — responsive blue-and-white styling
- `script.js` — mobile navigation and Facebook Messenger links

## Before publishing
The Facebook Messenger buttons are configured for `https://m.me/bysnooky`.

## Publish with GitHub Pages
1. Create a GitHub repository, for example `resume-online-maker`.
2. Upload `index.html`, `style.css`, `script.js`, and this README to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then click **Save**.
6. Wait for GitHub Pages to publish your site. Your URL will look like:
   `https://YOUR-GITHUB-USERNAME.github.io/resume-online-maker/`

## Notes
- The site is static and does not collect or store customer data.
- Government-related services are described as assistance only. Customers must complete required official steps and pay any applicable fees directly through official channels.
- For privacy, do not ask customers to send passwords, OTPs, or unnecessary sensitive personal information through Messenger.
